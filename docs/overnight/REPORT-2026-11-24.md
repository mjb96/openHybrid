## Blockers / surprises

- `gh pr merge` cannot switch the local `main` because another OpenCode worktree
  has it checked out. The merge itself succeeds; only the local branch switch
  fails. Work continued on short-lived branches from `origin/main`.
- Web verification takes roughly 7–9 minutes per PR; the full loop is
  CI-bound, not code-bound.
- H0 found more real defects than the plan anticipated: the equipment answer
  reverted on boot, stale bodyweight after a back-dated weigh-in, and a
  notification toggle that read OS permission instead of a preference.
